# 왕국 수호자 (Kingdom Guardian)

중세 판타지 영웅 디펜스 + 공성 게임. 외부 라이브러리 없는 HTML5 Canvas 단일 파일(`index.html`).

## 실행
`index.html`을 브라우저로 열면 바로 실행됩니다. 마우스·터치 모두 지원.

## 조작
- 빈 곳 탭/클릭: 영웅 이동 · 적 기지 탭: 기지 공격
- 길가 빈 터 탭: 건설 메뉴 · 타워 탭: 업그레이드/판매(두 번 눌러 확정) · 성 탭: 성문 업그레이드
- 스킬 버튼(Q/W/E 보조 단축키) · 일시정지(Space/P) · 2배속(2/F) · 메뉴 닫기(Esc)

## 밸런스 조정
`index.html` 맨 위의 `CONFIG`(수치)와 `MAP`(배치)만 고치면 됩니다.
그림을 이미지로 바꾸려면 `IMAGE_SOURCES`에 경로를 넣으세요.

## 개발 진행
- [x] 1단계: 지도·길·동굴 몬스터 생산·성문(에너지, 성벽 궁수, 목수 수리)·승리/패배
- [x] 2단계: 기사 영웅(이동·기본공격·스킬 3개·부활·자연 회복·레벨업)·적 기지 공격/파괴
- [x] 3단계: 골드·궁수탑·업그레이드·판매·성문 업그레이드(끓는 기름)
- [ ] 4단계: 투석기·마법탑·병력생성소 3종
- [ ] 5단계: 적 기지 3곳 완성·화면 스크롤·미니맵
- [ ] 6단계: 궁사·마법사·영웅 선택 화면
- [ ] 7단계: 중간보스·최종보스·아이템 드랍
- [ ] 8단계: UI 정리·밸런스·이펙트
